---
name: Guest chat visibility
description: The guest widget creates an automated welcome message before the visitor replies.
---

Admin guest-chat lists must be based on the presence of at least one message sent by the guest, not merely on a session or its latest message.  

**Why:** Opening the public chat creates a session and an admin welcome message, so session-only listing exposes conversations where the visitor never engaged.  

**How to apply:** Keep automated/admin-only sessions out of admin lists and unread totals, while returning the full message history for sessions that contain a guest message.
